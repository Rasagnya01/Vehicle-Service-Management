
# Vehicle Service Management System

## About
A menu-driven C programming project designed to manage vehicle service records.

## Features
- Add vehicle details
- Display all registered vehicles
- Search vehicles by registration number
- Update and delete vehicle records
- Track pending and completed services
- Calculate total service revenue
- Count vehicles by type
- Find the highest service charge

## Concepts Used
- C Programming
- Structures
- Arrays
- Functions
- String Handling
- Switch-case

## How to Run
1. Download the source code.
2. Compile using a C compiler:
   gcc vehicle_service.c -o vehicle_service
3. Run the program:
   ./vehicle_service

## Project Type
First-year B.Tech CSE academic mini project.
